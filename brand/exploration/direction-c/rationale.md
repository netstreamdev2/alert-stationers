# Full Circle

Swept curves and circular spot frames draw directly from the chasing-arrow badge. Standard UI icons stay unframed; movement appears only where it supports the metaphor. This is strongest for refresh, repeat purchase and brand recognition. Its risk is too many competing circles, so onboarding uses one focal ring and only one directional accent.

Draft exploration. Palette and arrow geometry require the master SVG. All UI is upright; 1.75px strokes with round joins. Refresh uses filled tapered crescents as a deliberate logo-motif exception within the outline set.
